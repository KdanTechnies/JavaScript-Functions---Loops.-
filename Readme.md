# JavaScript Functions & Loops

A practical JavaScript teaching session focused on helping students understand how functions and loops actually work, rather than memorizing syntax.

This repository contains the materials and project code I use while teaching JavaScript fundamentals with simple HTML and JavaScript.

## What This Session Covers

* Functions
* Function parameters
* `return`
* `for` loops
* `while` loops
* `if` statements inside loops
* Arithmetic operators
* Incrementing and decrementing
* Getting values from HTML inputs
* Connecting JavaScript to HTML
* Updating HTML with JavaScript

## What Students Build

The lesson uses a small HTML page connected to an external JavaScript file.

Students learn how to:

* Create and call functions
* Pass values into functions
* Return values from functions
* Repeat tasks using `for` loops
* Repeat tasks using `while` loops
* Combine loops with conditions
* Get user input from HTML
* Process that input with JavaScript
* Display the result back on the webpage

## Teaching Approach

I focus on making students understand **why the code works**, not just what to type.

For example, instead of simply teaching:

```javascript
for (let i = 0; i < 10; i++) {
}
```

I break the loop into its individual parts and explain what each part controls.

The same approach is used for functions, parameters, `return`, conditions, and DOM interaction.

The goal is for students to be able to look at a problem and build the logic themselves.

## Example

One of the projects from the lesson uses a function and a loop to generate a multiplication table from user input.

If a student enters:

```text
7
```

JavaScript generates:

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```

No CSS or external libraries are required.
